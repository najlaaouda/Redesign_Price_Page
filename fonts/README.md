# Fonts

Drop **29LT Bukra** font files into this directory.

## Required filenames

```
fonts/
├── 29LTBukra-Regular.woff2     (weight 400)
├── 29LTBukra-Regular.woff
├── 29LTBukra-Medium.woff2      (weight 500)
├── 29LTBukra-Medium.woff
├── 29LTBukra-SemiBold.woff2    (weight 600)
├── 29LTBukra-SemiBold.woff
├── 29LTBukra-Bold.woff2        (weight 700)
└── 29LTBukra-Bold.woff
```

## Licensing

**29LT Bukra is a commercial typeface** by 29 Letters Foundry (29lt.com).
You must hold a valid license to use it in production. Purchase at:
https://29lt.com/

## Fallback

Until the files are provided, the page automatically falls back to
**IBM Plex Sans Arabic** (loaded from Google Fonts — free, similar style).
No visual regression.
